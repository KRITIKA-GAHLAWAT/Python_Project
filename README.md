# Python Mini Project

This project contains three Python programs based on Python basics.

## Files

* `q1_result_analyzer.py` - Student Result Analyzer using variables, lists, loops, conditions, and functions.
* `q2_library_system.py` - Library Management System using dictionary, list, set, tuple, loops, and functions.
* `q3_shopping_cart.py` - Shopping Cart program demonstrating default parameters, mutable and immutable data types, and functions.

## Topics Covered

* Variables and Data Types
* Lists, Sets, Tuples, and Dictionaries
* If-elif-else
* Loops
* Functions
* Default Parameters
* Mutable vs Immutable Data Types

## How to Run

Run each Python file using Python 3:

```bash
python q1_result_analyzer.py
python q2_library_system.py
python q3_shopping_cart.py
```
